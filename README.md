
# Kaczmarz Method for Computational Medical Imaging

## Overview

This project documents undergraduate computational research
conducted at San Francisco State University involving the
Kaczmarz Method and its applications to CT/X-ray imaging.

The research investigated mathematical algorithms,
numerical methods, and computational techniques relevant
to image reconstruction.

## Research Components

- Implementation of the Kaczmarz Method in Python.
- Investigation of Kaczmarz methods with relaxation parameters.
- Radon Transform computations and sinogram visualization.
- Numerical evaluation of algorithm performance.

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
- scikit-image

## Background

The Kaczmarz Method is an iterative algorithm for solving
systems of linear equations.

The Radon Transform is a mathematical operation used in
tomographic imaging, including computed tomography (CT).
